# Campo Justo Puebla — Proyecto II (UdeG Virtual)

Plataforma web agrocomercial directa para conectar a **Campesinos**, **Locatarios** y **Transportistas** en Puebla y regiones colindantes.

## Avance Actual (Sprint 1 — Corte 11 de Noviembre de 2026)
- **CJ-01 / Tarea 1:** Diseño de formularios de registro e inicio de sesión (`Terminada`).
- **CJ-01 / Tarea 2:** Selector interactivo de rol: Campesino, Locatario o Transportista (`Terminada`).
- **CJ-01 / Tareas 3, 4 y 5:** Validación de datos, autenticación funcional y vistas por rol (`No iniciadas`, programadas en Sprint Schedule).

## Cómo ejecutar el proyecto
Requisitos: [Node.js](https://nodejs.org) 16 o superior.

```bash
npm install     # solo la primera vez
npm start       # abre http://localhost:3000
```

> No abras `public/index.html` con doble clic: es una app React y necesita `npm start` (o `npm run build`) para funcionar.

Para generar la versión de producción: `npm run build` (queda en la carpeta `build/`).
